# DocLens V0.3.1 Windows 便携版

2026-11-22。包含结构化解析与分层比较更新。

解压 `DocLens-V0.3.1-Windows.zip` 后，双击 `DocLens/DocLens.exe`。请保留完整目录及 `_internal` 依赖，不要单独移动 EXE。

- Word 解析保留标题层级、列表和嵌套表格单元格位置；PDF 保留页码。
- 比较优先按唯一章节标题分区，相邻且能对应的段落修改分开显示，再细化字符高亮。
- 保留双栏跳转、移动识别、文件夹检索和可选 AI 解释。
- 包内 `DocLens/示例/结构化比对/` 的 TXT 案例预期 3 组修改；`DocLens/示例/PDF比对/` 可检查跨页跳转和移动。

未新增扫描件 OCR、版本家族识别或语义检索。纯样式、自动编号和表格形状仍不作为正文差异。比对与检索可离线使用，AI 解释需要自行配置服务。
