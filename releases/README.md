# DocLens Windows 发布包

- V0.5.0 为当前版本，包含审阅清单、核对备注、HTML导出、词级高亮和AI分批覆盖。[发布说明](v0.5.0/README.md)
- V0.4.2 将AI等待上限放宽至120秒。[发布说明](v0.4.2/README.md)
- V0.4.1 包含学术比较、AI请求格式配置和加密记住API Key。[发布说明](v0.4.1/README.md)
- V0.4.0 原貌比较版，支持 Word/PDF 原始页面、缩放和页面差异标记。[发布说明](v0.4.0/README.md)
- V0.3.1 结构化比较版，内含 TXT 结构化与 PDF 测试样例。[发布说明](v0.3.1/README.md)
- V0.3.0 PDF 与移动识别版。[发布说明](v0.3.0/README.md)
- V0.2.1 DeepSeek 兼容版支持 DeepSeek 官方接口。
- V0.2.0 课程首版包含真实文档比对、文件夹检索和 AI 分析。
- T01 Windows 原型用于复现当时的技术验证。

解压完整目录后双击里面的 `DocLens.exe`（T01 原型使用 `DocLensT01.exe`）。保留与可执行文件放在一起的运行依赖。V0.5.0 也可从项目的 `dist/v0.5.0/DocLens/` 直接启动。

新版本的验证完成后，将发布 ZIP 放入对应版本目录。`dist/` 保留可运行目录。大型发布包保存在本机归档，Git 管理源码、说明和验证记录。
