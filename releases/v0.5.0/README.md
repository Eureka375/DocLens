# DocLens V0.5.0 Windows 便携版

2026-11-22。沿现有工程完成审阅与分析完整性增量，无新增运行依赖。解压完整ZIP后运行 `DocLens/DocLens.exe`，保留 `_internal`；项目内入口为 `dist/v0.5.0/DocLens/DocLens.exe`。

- 宽窗口提供常驻差异审阅列表，按类型、核对状态、AI类别筛选；搜索章节、正文或备注，点击跳回原文。
- 逐组已核对标记和备注，导出独立HTML报告；导出包含全部差异、证据位置、备注和AI状态，不受当前筛选影响。备注仅在本次比较保留，重比/换文件前请先导出。
- 文字视图可切换字符/词级高亮，英文词和小数完整定位，中文逐字；原貌预览标记保持原有精确文字位置。
- AI每批最多4组，每个请求12,000字符，一次最多20组、总60,000字符；先预览全部批次再确认顺序发送。
- 显示逐组覆盖与批次进度，失败/取消停止剩余发送并保留此前结果；补充未完成组仍须预览授权，不自动重发。每批最长120秒。
- 主界面及报告说明比较范围：已提取正文文字，格式、图片和公式等仍未比较。

保留原貌预览、TXT/DOCX/PDF混合比较、检索、加密记住服务设置及证据跳转。真实AI服务输出需人工核对；本轮未加入OCR、复杂PDF版面模型、通用章节语义对齐或Word插件。
