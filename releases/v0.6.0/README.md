# DocLens 0.6.0 多文档研究 MVP

日期：2026-11-24。独立分支 `codex/multi-document-mvp`，已同步远程 main `682aea3`。本地交付，不创建 GitHub Release。

## 运行

解压本目录的 `DocLens-V0.6.0-Windows.zip`，双击 `DocLens/DocLens.exe`。本机也可直接运行 [已构建程序](../../dist/v0.6.0/DocLens/DocLens.exe)。必须保留同目录 `_internal`，无需另装 Python。

点击顶部“多文档研究”，用“打开 / 重导入”选择随包的 `示例/多文档研究/demo-project.json`，立即查看四份文档的矩阵与笔记。或新建项目，批量选择 PDF/DOCX/Markdown/TXT。点击单元格再点击证据，右侧选中对应原文；“文档与目录”可跳章节；“笔记”支持关联当前证据。

“保存项目”保存本地 JSON（包含可用原文）；“导出 Markdown”生成完整可读报告；“导出共享包”生成可再次打开的 ZIP。附带原始文件默认关闭，但包内仍包含提取全文、证据和笔记。接收无原文包后，可重新导入相同原文补回原始文件而保留笔记。

## 保留与新增

保留双文档差异比较、原貌预览、文件夹检索、AI 审阅和报告；新增项目、多文档共同项、证据导航和离线共享。上述研究功能不依赖 AI，不需要密钥。

## 限制

- 仅内置词典，未知实体不识别；使用线索属于规则推断，需核对，不是实际使用的最终认定。未发现不等于不存在。
- PDF 需要文字层，最多300页，不做 OCR；DOCX/PDF 研究视图使用提取正文，不能完整保留图表、公式或原版式。旧双文档原貌预览仍可用，Word 原貌需要本机 Word。
- 文本导入默认 UTF-8；每文档10 MiB/100000字符、项目50份/100万字符、10000条命中、500条笔记。项目/共享包100 MiB，ZIP同时检查解压总量。Markdown 支持源文本和 ATX 目录，内部锚点需要支持 HTML 锚点的阅读器。
- 未实现在线协作、人工实体/状态修正、用户词典、OCR、复杂跨句语义。这些不属于本次规则 MVP。
- 本机未找到 Inno Setup 编译器，本次提供便携目录和 ZIP；安装脚本与 Windows 构建流程已更新到0.6.0，本次未生成或验证安装包。
