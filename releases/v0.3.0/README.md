# DocLens V0.3.0 Windows 便携版

解压完整目录，双击 `DocLens/DocLens.exe`。使用 `DocLens/示例/PDF比对/` 内的两份 PDF 可试用跨页跳转和段落移动识别。比对和文件夹检索可离线运行。

- 支持文本型 PDF 和 TXT、DOCX 混合比对。PDF 可加入文件夹检索，差异和搜索结果带页码与行号。
- 两版中唯一且完全相同、可配对的移动文字显示为蓝色。直接选择差异编号可跳到移动前后的两处位置。
- 长文档会尝试按稳定文本拆分远距离修改。AI 证据预览会显示对应位置。

纯扫描件需先做 OCR。复杂 PDF 的阅读顺序依赖文字提取结果，加密 PDF 需先另存为未加密副本。
