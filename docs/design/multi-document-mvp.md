# DocLens 多文档研究 MVP 需求规格

版本：0.6.0；日期：2026-11-24；基线：main / 60a777a。

## 目标与范围

面向阅读多篇论文的学生和研究人员：将文档归入可再次打开的本地项目，发现共同数据集和方法，核对证据并记录、离线共享笔记。依据本次明确需求及引用对话中老师提出的四项需求编写，不推断未提供的历史回复。

保留现有双文档版本比对、文件夹检索、原貌预览、AI 分析及审阅导出；新增独立“多文档研究”入口。不要求 API Key，不自动联网。实现选择：沿用 Python/PySide6/QML 和现有解析器，JSON 项目快照、规则词典与证据匹配、ZIP 离线共享。

## 功能需求

- R1 项目：新建、打开、保存项目，保存文档的解析快照、散列、结构、证据和笔记；批量导入，每份独立报告成功、重复、失败或部分提取。项目保存可移动到其他目录，打开不依赖原始路径。删除文档同时移除其笔记关联，保留笔记正文。
- R2 格式：PDF、DOCX、Markdown（.md/.markdown）、TXT。每份沿用 10 MiB、100000 字符限制；PDF 最多300页且需文字层，不做 OCR。DOCX 沿用正文/表格提取及未提取内容警告。文本默认 UTF-8（含 BOM）；研究入口不提供旧编码自动猜测。Markdown 按源文本展示，识别 ATX 标题，非完整渲染器。项目最多50份文档、总正文最多100万字符。
- R3 共同项：内置有限数据集/方法别名词典，边界匹配、大小写归一；同一规范项在至少两份文档出现即为共同项。矩阵保留所有已发现项，逐文档显示“使用线索 / 仅提及或待核对 / 否定使用 / 未发现”，并显示证据数量。“使用线索”为规则判断，必须人工核对，不等于已确认实际使用。未发现不等于不存在。
- R4 证据：每次命中保留文档ID、原文半开字符区间、逐字引文、段落/页行位置及章节路径。点击矩阵单元格列出该文档该项的全部证据；点击证据跳转并选中解析正文中的原文。以句内使用/否定表达区分状态；引用/相关工作优先保守判定。一格存在多种状态时优先显示使用线索，但全部证据仍可查看。
- R5 导航：文档章节目录使用 Markdown 列表和内部链接，点击进入同一解析快照的标题并选中。无标题文档仍可全文阅读。PDF/DOCX 的研究视图为提取正文，不保证原版式、公式、图片与页内坐标；保留旧双文档原貌视图。
- R6 笔记：新增、编辑、删除笔记；可关联当前选中证据，显示并可跳回该证据；保存、重新打开仍有效。无证据笔记允许保存。Markdown 导出包含矩阵、文档目录、结构导航、笔记、证据引文和可用内部锚点，不使用本机绝对路径。
- R7 离线共享：ZIP 包含版本化项目快照和 Markdown 报告；原文默认不附带，由用户明确勾选后包含导入时原文。接收者可重导入，不需原路径。即使不附原文，包仍含提取正文、引文、笔记，界面必须告知。包不含 API Key、AI 设置或个人绝对路径。未知版本、无效结构、越界/不匹配证据、ZIP 重复项及超限包应拒绝，不直接解压不可信路径。

## 规则边界与后续需求

词典初版覆盖 MNIST、CIFAR-10、ImageNet、SQuAD、GLUE、COCO 和 BERT、ResNet、Transformer、SVM、Random Forest、CNN。未知实体不推断，词典外共同项、表格语义、跨句指代、中英同义改写及使用主体识别均不保证。规则确定性和证据可追溯优先于召回率。后续可增加用户词典、人工纠正状态、可选 AI 辅助（需另行设计授权）、OCR、协作冲突处理；不属于本次 MVP。

## 验收标准

- A1：四份覆盖四种格式的合成论文可一起导入；重导不重复；一份损坏文件不阻断其他文件；部分提取警告可见。
- A2：样例的 CIFAR-10、BERT 共同项及别名合并正确；“相关工作提及”“明确采用”“未使用”有不同状态；未命中的单元格写“未发现”。同句含多个不同使用状态的实体应保守处理。
- A3：所有证据引文等于快照对应区间；中文与 emoji 之前的偏移经 UTF-16 转换后仍正确选中；章节点击跳转。
- A4：项目保存重开、笔记增改删及证据关联闭环通过；删除文档后不留悬空证据关联。
- A5：Markdown 导出可阅读并可点击内部锚点；带/不带原文包都可重导；损坏/超限/恶意包拒绝且保留当前项目。
- A6：原有自动化回归测试通过；新增核心和桌面流程测试通过；Windows 构建成功，实际启动冻结版本并验证研究入口。所有运行结果和已知限制写入验证报告；无实际检查的项目明确列为未验证。

## 非功能要求

所有导入和存储错误应有可读提示；长任务放后台，工作期间阻止并发写入和关闭造成状态损坏；项目写入采用同目录临时文件原子替换。最多10000条实体证据、500条笔记（每条最多20000字符）；项目文件和共享包均最多100 MiB，共享包同时限制解压总量。规则仅检查实体附近的有界子句；Markdown 每条证据附带有限上下文，完整正文仅输出一次。导出不自动上传、不创建 GitHub Release、不合并 main。交付便携 Windows 目录/ZIP，安装包在工具可用时提供。
