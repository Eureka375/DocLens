# 原文档排版比较

用户选择：优先保留原排版，允许依赖本机 Microsoft Word。目标是两侧像查看原文件一样显示页面，并在页面上标记正文差异，而不是把正文统一排成纯文本。

方案选择：DOCX 通过本机 Word 将临时副本只读导出为 PDF，PDF 直接渲染原页面；已有文本比较继续产生证据。相比 HTML 重建，此方案更适合保留分页、图片和复杂表格；相比内嵌可编辑 Word，统一页面预览便于双栏缩放和差异叠加。缺少 Word 时明确回退文字视图。

页面：保留文件选择和差异导航，两侧新增“原貌 / 文字”切换和缩放。原貌显示白色文档页、页码，删除红色、新增绿色、移动蓝色；差异导航同步滚动。TXT 保留现有文字显示。原貌是只读预览，不编辑源文件，也不新增字体/样式差异检测。

实现边界：渲染与转换在工作线程执行；Word 子进程禁用宏、禁用链接更新、只操作临时副本，关闭时不保存。生成的页面仅存临时目录，重置/退出清理。页数、像素、文字和磁盘预算限制预览工作量。PDFium 所有调用串行互斥。坐标来自实际 PDF 字形；只在文本能可靠对应时标注，无法对应时保留原貌并提示使用文字视图核对，不在页面上猜测位置。

验证：文本/表格/图片/分页的 DOCX 与 PDF，页面坐标、相邻数字修改、重复文字、旋转页、取消与导出失败，原文件哈希不变，窗口导航与回归。源代码与重新打包后的便携版均验证，Word 依赖写入发布说明。
