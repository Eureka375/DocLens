## 3. 产品定位与边界

DocLens 是面向高校学生与科研人员的多文档智能分析工具（Multi-document Analysis Tool），帮助发现关联、差异与关键信息，形成可追溯、可验证、可复用成果，降低多文档阅读、检索、比较与研究分析的时间及操作成本。

设计原则：研究项目为中心，分析任务驱动，真实原文证据为基础，结构化结果为主要输出，本地与隐私优先，以功能效果决定技术，不强制 AI；传统算法或轻量模型能够可靠解决的问题优先使用，保留原有版本比对。

不以通用文件自动整理、完整文献管理/参考文献排版、通用 AI 聊天、专业 PDF 编辑、通用知识管理、在线学术搜索、实时多人办公或自动论文写作为目标。DocLens 与 FolioMind 是独立项目，不混淆定位、代码与成果。

Zotero、Adobe Acrobat、ChatGPT、NotebookLM、Elicit 等仅作为原需求中的竞品背景；本次未开展竞品实测。多文档分析、语义检索、引用和提取并非独有能力。本地优先、任务驱动、可视化结构成果、证据绑定、范围/维度可控、成果持续复用与保留 Diff 是差异化目标，不宣称已形成优势。

## 4. 用户、场景与痛点

### 4.1 用户优先级

- 用户 P0：高校学生（课程资料、文献、毕业论文、课程设计）；科研人员（综述、方法、数据集与实验结果）。
- 用户 P1：软件开发人员（技术、需求及方案比较）；企业办公人员（项目资料、报告及汇总）。
- 用户 P2：法律从业者（合同条款）；行业研究人员（财报、行业观点）。

底层解析、检索、关联与提取保持通用，不按行业分别建设系统。上述 P0–P2 是用户优先级。

### 4.2 典型场景

- **SC01 学术文献分析**：多论文中的共同数据集、方法、对象、指标和结论。
- **SC02 跨文档检索**：用关键词或自然语言找回记忆中的概念与原文。
- **SC03 结构化比较**：自定义数据集、方法、结果、训练轮次、复杂度、局限性等维度，形成矩阵。
- **SC04 版本比对**：新旧版新增、删除、修改、移动、拆分、合并及含义辅助分析。
- **SC05 成果复用**：保存检索、关联、矩阵和证据为笔记，编辑、补充、导出及分享。

### 4.3 痛点与用户需求追踪

- **PA01 / UR01，痛点 P0**：跨文档查找低效 → F03 关键词与语义检索。
- **PA02 / UR02，痛点 P0**：难主动发现共同点 → F04 自动关联发现。
- **PA03 / UR03，痛点 P0**：难系统比较 → F05 自定义维度与矩阵。
- **PA04 / UR04，痛点 P0**：结论不可信 → F07 原文追溯。
- **PA05 / UR05，痛点 P1**：难保存复用 → F08 记录与笔记。
- **PA06 / UR06，痛点 P1**：阅读导航困难 → F02 阅读及章节。
- **PA07 / UR07，痛点 P1**：隐私与成本 → F09 本地及隐私。
- **PA08 / UR08，痛点 P2**：版本变化难识别 → F06 保留既有能力。

痛点价值排序不将 F06 或隐私降为可删除功能。F01 是各场景共同基础。

## 5. 功能体系与 75 项候选子功能

基础层 F01/F02；核心分析层 F03/F04/F05/F06；成果层 F07/F08；系统支撑 F09。以下每项保留原编号及含义，阶段标签依第七阶段约束。MVP 为交付 P0；“后续”未统一指定 P1 或 P2 时，不擅自确定。

### F01 文档管理（8 项）

- **F01-01 项目空间 [MVP]**：创建、编辑、删除独立研究项目。
- **F01-02 文档导入 [MVP]**：单文件、批量及文件夹导入。
- **F01-03 格式支持 [MVP]**：PDF、DOCX、Markdown、TXT。
- **F01-04 文档组织 [MVP 基础组织；高级分组标签后续]**：分组、标签、排序、筛选；高级深度后置。
- **F01-05 重复检测 [MVP]**：识别重复导入相同文档。
- **F01-06 解析状态 [MVP]**：等待、解析中、成功、失败及部分提取等状态。
- **F01-07 文档更新 [MVP 基础检测；实时监控/高级增量后续]**：识别修改，标记相关索引及结果受影响，用户决定更新。
- **F01-08 文档移除 [MVP]**：默认不删除源文件，提示关联影响。

边界：不擅自移动、修改、重命名或删除原始文件，不承担全电脑整理。验收 AC-F01：混合批次含四格式、重复、同名异文及损坏文件，逐份处理、失败隔离；保存重开关系完整；移除源文件仍在；变更时旧结果不覆盖。

### F02 文档阅读与章节导航（8 项）

- **F02-01 文档预览 [MVP]**：软件内阅读；提取文本与原始 PDF 阅读区分。
- **F02-02 文档内搜索 [MVP]**：当前文档关键词查找。
- **F02-03 章节识别 [MVP]**：标题和层级。
- **F02-04 Markdown 导航 [MVP]**：可点击结构目录。
- **F02-05 原文高亮 [MVP]**：检索、差异及证据。
- **F02-06 多文档切换 [MVP]**：多标签页。
- **F02-07 并排阅读 [后续；版本 Diff 既有双栏保留]**：普通文档双份阅读。
- **F02-08 阅读位置记录 [后续]**：上次位置保存。

Markdown 不完全替代原始 PDF。验收 AC-F02：目录正确定位，文字高亮对应同一版本；无标题仍可读；多标签保留当前任务状态；复杂版式或部分解析明确告知，不能伪装完整支持。

### F03 跨文档信息检索（8 项）

- **F03-01 关键词检索 [MVP]**：多文档指定词。
- **F03-02 语义检索 [MVP]**：含义相关、表达不同。
- **F03-03 检索范围 [MVP]**：全部项目、指定分组或文档；分组范围依基础组织能力提供。
- **F03-04 结果排序 [MVP 基础；高级筛选后续]**：相关性、文档、位置。
- **F03-05 上下文展示 [MVP]**：命中及必要上下文。
- **F03-06 结果定位 [MVP]**：点击跳转。
- **F03-07 检索历史 [后续专用体验]**：历史检索任务；MVP 仍须保留 F08 的基础任务记录。
- **F03-08 结果收藏 [MVP]**：加入笔记。

输入为查询和范围；输出为文档、片段、相关性和位置。尽可能区分实际使用、仅提及、否定和无法判断，不能把相似度当事实可信度。验收 AC-F03：中文跨英文、同义、缩写、短词和实体变体正反例；范围隔离、上下文、跳转与收藏；满足 ACC03/04 和 NFR01-07/08。

### F04 跨文档关联发现（8 项）

- **F04-01 相同内容发现 [MVP]**：重复文本和共同段落。
- **F04-02 相似内容发现 [MVP]**：语义相似而表述不同。
- **F04-03 共同实体识别 [MVP]**：数据集、方法、指标等开放实体。
- **F04-04 共同主题识别 [MVP 基础；复杂主题后续]**：文档主题关联。
- **F04-05 观点关联分析 [后续]**：观点一致/冲突辅助判断。
- **F04-06 关联分组 [MVP]**：共同内容文档组。
- **F04-07 关系可视化 [MVP 列表/基础展示；高级关系图后续]**。
- **F04-08 人工校正 [MVP]**：确认、删除、修正关联。

自动模式只选文档，定向模式再选类型，两者均须支持。实体类型可预设，实体名称不能限于预设词库；词重合不等于学术关联。验收 AC-F04：四级分别评估；未见实体、别名、同名异义、相关工作、否定、模板与参考文献干扰；满足 ACC05/06，证据满足 ACC09/10；相似与主题质量阈值待决。

### F05 结构化多文档比较（10 项）

- **F05-01 比较对象选择 [MVP]**：两份及以上文档。
- **F05-02 预设模板 [MVP 基础；模板保存后续]**：论文/技术方案等。
- **F05-03 自定义维度 [MVP]**：用户定义提取目标。
- **F05-04 信息提取 [MVP]**：逐篇指定信息。
- **F05-05 比较矩阵 [MVP]**：表格结构结果。
- **F05-06 共同点归纳 [MVP]**。
- **F05-07 差异点归纳 [MVP]**。
- **F05-08 缺失信息标记 [MVP]**：未找到、不适用、解析失败等分开。
- **F05-09 结果编辑 [MVP]**：人工修改及确认。
- **F05-10 比较结果更新 [正式版增量]**：仅补新增文档/维度；MVP 标记过期并允许用户重分析，不承诺高级增量执行。

输出矩阵、共同点、差异点与证据；不得将不同条件/数据集的指标直接排名方法优劣。验收 AC-F05：200 标注字段包含新维度、数值单位、多值、跨段、缺失、歧义冲突与语义角色；ACC07 ≥90%，另报告覆盖及错误填充，禁止靠全部未找到抬高准确率。

### F06 文档版本比对（8 项）

- **F06-01 版本选择**：旧版与新版。
- **F06-02 文本差异**：新增、删除、修改。
- **F06-03 结构差异**：移动、拆分、合并。
- **F06-04 差异高亮**：并排显示。
- **F06-05 差异导航**：前后跳转。
- **F06-06 语义变化分析**：重要修改含义。
- **F06-07 变化摘要**。
- **F06-08 结果保存**：保存及导出报告。

八项均按“优先复用、审查并回归现有能力”处理，不能宣称现有代码完整支持所有结构差异。既有且通过回归的能力留在 MVP；复杂匹配优化、多版本演化后续；未实现候选能力须记录差距，不静默删除也不假称具备。传统 Diff 与可选 AI 分析结合，临时快速比对无需完整项目。

验收 AC-F06：50 组版本测试，文本差异 ACC08 F1≥95%，两份20页文本比对≤5秒；结构差异按实际可支持类别单列结果，旧双栏与入口回归；语义解释需证据，未经授权不外传。

### F07 原文证据追溯（7 项）

- **F07-01 证据引用 [MVP]**：结论绑定真实原文。
- **F07-02 来源记录 [MVP]**：文档、页码、章节、段落，只有真实可用信息才展示。
- **F07-03 原文跳转 [MVP]**。
- **F07-04 多来源证据 [MVP]**：一个结论多个文档。
- **F07-05 证据状态 [MVP]**：明示、推断、不足、冲突。
- **F07-06 人工验证 [MVP]**：确认或否定。
- **F07-07 证据失效检测 [MVP 基础；完整历史版本管理后续]**。

宁可未找到，不生成不存在的证据。验收 AC-F07：有效引用真实性及定位100%，跳转≤1秒；中文/emoji/重复句及版本变更测试；找不到旧版时明确失效，禁止跳到新版近似片段；原文是否支持结论单独评估。

### F08 分析记录与笔记（10 项）

- **F08-01 任务记录 [MVP]**：任务及参数。
- **F08-02 手动笔记 [MVP]**。
- **F08-03 原文摘录 [MVP]**。
- **F08-04 结果转笔记 [MVP]**。
- **F08-05 笔记编辑 [MVP]**：Markdown。
- **F08-06 证据绑定 [MVP]**。
- **F08-07 结果导出 [MVP Markdown/CSV；HTML及高级报告后续]**。
- **F08-08 笔记分享 [MVP]**：文件及基础分享包导入导出。

- **F08-10 结果复用 [MVP 基础复用；增量分析/高级组织后续]**。

初期无账号与实时协同。验收 AC-F08：任务转换保留来源；Markdown 笔记自动保存窗口≤5秒；Markdown/CSV 值与证据对应；分享包换目录重导可查看历史，坏包拒绝且不损坏当前项目；重启不丢已保存成果。

## 6. 已确认业务与交互

### 6.1 六项交互决策

1. 研究项目为中心，同时支持临时快速分析。
2. IDE 式多面板工作台。
3. 自动发现与指定类型发现并存。
4. 任务可直接转换，复用文档与证据。
5. 文档变化标记结果过期，由用户决定更新。
6. 导出文件分享，支持后续导入复用。

### 6.2 工作台结构

最左功能栏切换入口；左资源区承载项目、文档、历史任务、笔记；中央展示文档/分析结果；顶部多标签切换文档与任务；右辅助区提供证据、目录、笔记；底部显示任务进度、错误与系统状态。面板可折叠、调整宽度、关闭。

候选页面为项目工作台、文档库、跨文档检索、关联分析、多文档比较（含版本比对入口）、分析笔记、设置。页面具体命名为候选，六项决策与面板职责已确认。分析、原文和笔记在同一环境中联动，切换不丢分析状态。

### 6.3 业务对象

Project、Document、DocumentVersion、Section、ContentBlock、Chunk、AnalysisTask、AnalysisResult、Evidence、Entity、Note。ContentBlock 是可定位原始块，Chunk 为检索/模型片段，可以跨块但必须保留来源映射。

### 6.4 用例

- **UC01 导入**：建项目 → 文件/文件夹导入 → 自动解析与索引 → 逐份状态；已完成文档立即可分析，单份失败不阻断，类型/内容不支持明确提示。
- **UC02 检索**：查询 → 选范围和模式 → 文档与片段 → 上下文/原文 → 收藏或进一步分析。
- **UC03 关联**：选文档 → 自动或定向 → 发现与分组 → 证据确认 → 笔记或比较。
- **UC04 比较**：选对象及模板/维度 → 逐篇提取 → 矩阵 → 单元格证据 → 编辑确认 → 保存导出；正式版支持只补新增文档或维度。
- **UC05 版本**：新旧版 → 文本/结构变化 → 双栏差异 → 含义 → 报告；支持临时快速入口。
- **UC06 验证与笔记**：任意分析 → 统一证据面板 → 原文核对 → 确认/否定/修正 → 关联笔记保存。

任务转换：检索→关联（命中文档及证据）；检索→比较（命中文档）；关联→比较（文档及共同实体）；比较→检索（维度及相关文档）；任意分析→笔记（结果及证据）。转换后新任务保留来源任务 ID，旧任务不被覆盖（实现细节为建议）。

### 6.5 生命周期与更新一致性

已确认用户状态：待执行（改参数/启动/取消）、执行中（进度/取消）、已完成（看/编辑/验证/导出）、执行失败（错误/重试）、已取消（重启）、待更新（旧结果/重分析）、已归档（历史查看）。技术上可增加持久化的取消中、部分完成子状态，见技术设计。

MVP 必须基础识别文档变化，标记受影响结果待更新、证据失效及索引过期。实时文件监控、全自动更新和高级增量后置。建议在打开/用户刷新时做散列检查；具体触发频率待决，但不得因此省掉检测能力。用户决定更新；不得自动覆盖历史分析或自动外传重算。

旧版本存在时仍指向旧版；源文件被覆盖/删除且未存旧版时，历史结果仍保存，但明确“历史原文不可定位”。不保证无限保存所有源文件版本，不静默跳新版。

## 7. 非功能需求基线

以下所有数值是确认的初步目标，除明确列为建议者外均须验收。标准规模为30份文档、约500页文本型 PDF；DOCX/MD/TXT 的正确性另测，不将页折算未定义的数据冒充此性能基准。

### NFR01 性能效率

- **NFR01-01** 冷启动≤5秒。
- **NFR01-02** 打开已有项目≤2秒。
- **NFR01-03** 普通 PDF 首页≤2秒。
- **NFR01-04** 页面/工作区切换≤300ms。
- **NFR01-05** 单篇10页 PDF 解析≤5秒。
- **NFR01-06** 500页解析与索引≤120秒。
- **NFR01-07** 已建索引关键词检索≤500ms。
- **NFR01-08** 已建索引语义检索≤2秒。
- **NFR01-09** 10篇论文定向关联≤60秒。
- **NFR01-10** 10篇论文×5维度比较≤120秒。
- **NFR01-11** 两份20页文档文本比对≤5秒。
- **NFR01-12** 证据跳转≤1秒。

一次解析、多次复用，避免重复索引及无必要模型调用，后台进度/取消/重试。模型冷启动与预热单列；OCR/扫描/复杂图表单测；自动关联发现单独测量，不套定向60秒指标。硬件、计时边界、重复次数及最终统计判定须先冻结，不能拿平均数替代未定义的验收口径。

### NFR02 准确性与可信度

- **ACC01** 文本提取准确率≥98%。
- **ACC02** 章节识别 F1≥90%。
- **ACC03** 关键词召回率≥98%。
- **ACC04** 语义 Recall@10≥85%。
- **ACC05** 共同实体 Precision≥85%。
- **ACC06** 共同实体 Recall≥75%。
- **ACC07** 结构化提取准确率≥90%。
- **ACC08** 文本版本差异识别 F1≥95%。
- **ACC09** 有效原文证据定位准确率100%。
- **ACC10** 有效引用真实性100%。

Precision=正确识别/系统识别；Recall=正确识别/人工真值；F1=二者调和平均；Recall@10=前10覆盖相关结果/全部标注相关结果，再对查询汇总。字段准确率基于人工标注，单报覆盖及错误填充，防止全部未找到虚高。

引用真实性、定位准确性、结论支持性分开。前两项有效证据100%，不代表结论100%正确；后者独立标注、阈值待确认。无效候选应被阻止进入有效结果，同时统计拒绝率、证据覆盖，不能通过全部拒绝实现空集100%。

状态须区分原文明示、分析推断、未找到、歧义、冲突、不适用、解析失败、证据失效、人工确认/修正，不填造引用或字段。

### NFR03 容量与扩展性

首阶段目标 / 后续扩展目标：

- 单项目文档30 / 500份；总页500 / 10,000页。
- 单份文本 PDF 200 / 1,000页。
- 单次比较10 / 100份；维度10 / 30个。
- 单次关联30 / 100份。
- 独立项目10 / 100个。
- 单项目笔记100 / 1,000条。

以上为测试目标，不是固定硬上限。30份标准规模与10份单次比较不同；性能比较为10×5而非容量10×10。避免无条件 n(n−1)/2 全量两两分析。

### NFR04 可靠性与恢复

- **NFR04-01** 默认不修改、移动、删除源文件。
- **NFR04-02** 笔记未保存窗口≤5秒。
- **NFR04-03** 重启识别中断任务、支持重试。
- **NFR04-04** 单文件失败隔离。
- **NFR04-05** 损坏索引可重建。
- **NFR04-06** 已保存成果重启完整。
- **NFR04-07** 更新不覆盖历史结果。
- **NFR04-08** 支持基本备份恢复并验证；完整管理界面后置。

### NFR05 易用性

主要操作步骤：新建并导入≤4；关键词查询≤2；自动关联≤3；结构化比较≤4；证据1次点击；证据存笔记≤2次点击；导出≤3步。

候选用户体验测试（建议，非已完成调研）：至少5名非开发学生，无指导核心任务完成≥80%，理解入口≤5分钟，首次基础检索≤3分钟，满意度≥4/5。测试协议及是否作为发布强制门槛待确认。

### NFR06 安全与隐私

- **NFR06-01** 文档、索引、笔记默认本地。
- **NFR06-02** 未经授权不外传正文。
- **NFR06-03** 外部最小传输。
- **NFR06-04** 密钥不明文进入日志/导出。
- **NFR06-05** 清理项目及缓存。
- **NFR06-06** 导出前确认原文及本地路径内容。
- **NFR06-07** 日志默认无敏感正文。
- **NFR06-08** 文档不可信指令不能自动执行系统操作。
- **NFR06-09** 明确离线模式。

强制离线：管理、阅读导航、关键词、相同文本、传统 Diff、已有结果、笔记及导出。语义优先离线；复杂语义关联/提取是否完全离线取决于最终模型。缺少本地模型应明确能力不可用，不静默转外部。

### NFR07 兼容性

P0：文本 PDF 阅读/解析/检索/分析/定位；DOCX 文本/标题/段落/基础表格；Markdown 文本及标题；TXT。P1：扫描 PDF OCR。P2：XLSX、PPTX、HTML、DOC。复杂公式、图中文字、特殊排版、复杂表格不保证完整，必须提示限制。

建议基础环境：Windows10/11 x64、4核、8GB RAM、无独显；增强环境：6核以上、16–32GB、可选8GB GPU。macOS/Linux 非课设强制平台。开发者自述31.71GB RAM、RTX4060 Laptop、Windows，预计8GB显存；本轮未检测，不能当已核验硬件。

### NFR08 可维护性

核心与前端解耦，算法/模型可替换，解析器可扩展，接口输入/输出/错误码文档化，每项核心功能自动回归，兼容历史项目，标准构建安装发布与可诊断日志。核心模块80%行覆盖率为建议目标，不能以覆盖率代替功能正确性。

### NFR09 资源与成本

初步目标：空闲内存≤500MB，基础分析峰值≤2GB（不含独立模型），空闲CPU≤2%；本地模型不超设备预算；后台并发可配置；磁盘缓存可查看/限制/清理。软件与模型分计。付费模型逐步支持 Token、预算及结果缓存，高级统计可后置；基本隐私授权和资源不失控不可后置。

### 7.10 标准测试集建议

解析40份、关键词50查询、语义100查询、关联30组、提取200字段、版本50组、异常20场景；压力10/30/100文档；用户至少5名。记录平均、P95、冷启动/预热、内存/显存。E01首轮20 PDF，后续解析40份，两者不同阶段不冲突。

质量排序：准确性与证据真实性 > 数据安全与可靠性 > 性能 > 功能覆盖。此排序不是允许自行删功能或降阈值的授权。

## 8. 优先级、MVP 与一致性裁决

交付 P0=MVP必须；P1=正式版完善；P2=后续扩展；P3=本阶段不开发。与用户优先级、痛点优先级分开使用。

MVP 九模块：F01基础项目/文档；F02阅读/章节/Markdown；F03关键词及语义；F04相同/相似/共同实体/基础主题及两种模式；F05自定义提取及矩阵；F06复用版本比对；F07统一证据与人工验证；F08分析记录、Markdown、MD/CSV与分享包重导；F09本地隐私后台任务。详见第5节逐项深度标签。

一致性裁决：

1. 旧文档将语义、自动实体、自定义矩阵排除首版的规定不适用于新基线；F03/F04/F05全在MVP。
2. F01-07候选更新需求在MVP保留基础变化检测、索引受影响标识、F07-07失效与结果过期；高级实时监测和增量后置。用户决定更新，不覆盖历史。
3. 历史成果必须持久保存；未保存旧源文件时不保证重开旧原文，必须显式失效。
4. 分享是MD/CSV与基础ZIP导入导出，无账号云同步或实时协同。
5. 已存在且回归通过的版本比对继续保留；普通并排阅读可后置，不删除旧Diff双栏。
6. 基础主题进MVP，复杂观点冲突后置；矩阵中矛盾证据标记仍必需。
7. 备份基本可恢复性进MVP，完整管理界面后置；硬容量旧限制须审查，不直接当新目标。
8. 100%仅有效引用真实性及定位，结论支持单独评价；20份PoC与40份完整集分阶段。
9. 正式版增量提取只补新文档/维度；MVP重算也要用户决定、保留旧结果与范围。
10. 未验证工程能力不得靠“复用”二字宣布已实现；性能口径必须先冻结。

阶段A PoC；B MVP闭环；C 正式版质量/增量/交互；D 大规模与高级解析研究。不在源码审查/PoC前承诺固定工期。

本阶段不开发：全电脑整理、在线学术搜索、自动论文写作、实时协同、账号云同步、完整知识图谱、复杂公式图像理解、通用自主Agent、全平台适配。
