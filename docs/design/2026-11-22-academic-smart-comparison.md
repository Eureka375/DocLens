# 学术文档智能比较增量设计

用户已确定传统 Diff + AI 语义分析，并授权按现状选择本轮范围、直接开发。沿用当前 Python / Qt 工程，保留预览、检索和现有接口；不涉及 FolioMind。

## 当前基础与选择

现有 Snapshot / TextBlock / Span 已统一 TXT、DOCX、PDF，包含原文偏移、标题路径、表格路径和 PDF 页码。compare 已按章节、段落、字符比较并识别完全一致的移动。AI 已有授权预览、HTTPS、请求限额、缓存与失败后继续本地比较。基线 75 测试通过。

选择增量补齐，避免重写解析器或引入另一套界面；完整 OCR、公式和格式比较需要独立实现和验收，本轮不引入。

## 本轮接口与行为

- 保守识别短编号标题（1 Introduction、2.1 实验方法）以及常见无编号学术章节；编号后的名称须命中内置学术标题词表，避免样本数和带单位小数被误判。自定义名称退回普通段落。不修改显示文字与偏移。DOCX 继续以原生标题样式为准。
- Change 保留字符编辑字段，追加词级编辑范围；英文按词、数字按连续数字片段、中文逐字，仍以原文 Unicode 码点定位。不声称实现中文分词或公式语义比较。
- prepare_analysis 增加可选 provider 参数：auto 保持现有兼容行为；compatible、json、deepseek 显式控制 Chat Completions 请求格式。独立 ProviderConfig 负责请求参数，凭据仍由现有网络控制器管理，不持久化。
- AI 提示优先研究问题、方法、数据、结果、结论与引用，也保留原有通用分类。每项引用某差异组时，必须覆盖该组实际提供的全部侧证据；只证明引用存在和双侧完整，不能证明模型解释真实。
- 证据增加章节路径，发送内容继续仅包含所选差异。界面选择请求格式，发送前显示格式；失败明确保留本地比较，不自动重发。

## 验收与边界

测试覆盖章节防误判、词级原文范围、请求配置与缓存隔离、单侧引用拒绝、插入/删除接受、学术分类、界面参数传递和故障后原文跳转。运行完整 pytest。

后续：真实模型凭据验收、OCR、复杂 PDF 阅读顺序、公式/图表/文献条目专用结构、改写移动、中文分词与语义正确率数据集。界面本轮保留字符高亮，词级范围供后续显示模式使用。
