# DocLens 新需求工作台原型设计

日期：2026-11-26。依据：[需求规格](requirements.md)、[技术方案](technical-design.md)。交付：[本地交互原型](../../examples/mvp-workbench/index.html)、[操作指南](../../examples/mvp-workbench/README.md)。

## 目标与本次实现方式

用户希望根据确认文档看到原型；只有已有应用满足新 MVP 时才省略原型。检查当前工作区后，现有 0.6.0 具备旧版项目、四格式导入、固定实体规则矩阵、证据、笔记和离线共享；新基线中的语义检索、开放实体、基础主题、自定义维度提取未在所查模块中实现。因此采用独立、可丢弃的本地交互原型说明新产品，而不修改正式应用。

这是有限检查：查看 pyproject.toml、research.py、workspace/research UI 相关检索结果、既有原型及历史验证文本；未完成 AUD-01，未核验 main 最新远端源码，未重跑旧产品测试/构建，不将旧报告当本轮实测。

候选呈现方式为静态原型图与本地可点击页面。此次选择后者，并从真实页面生成截图，既能看布局，也能体验证据和任务流；不搭建托管服务，不接外部模型。原有 `examples/desktop-prototype/` 保留，不覆盖此前较窄的关键词版。

## 视觉与布局

桌面研究工具，内容优先。使用深海军蓝功能栏 `#192b4b`、靛蓝操作与选中态 `#3858d5`、正文墨色 `#25344c`、中性底 `#f5f7fb`、结构线 `#e3e7ef`、验证绿色 `#237b69`。普通界面使用 Windows 中文系统字体，英文研究原文使用 Georgia，正文与工具区域有清楚的字级差异。

沿用确认的 IDE 布局：44px 标题、58px 功能栏、218px 资源区、中央可滚动任务区、318px 证据区、28px 状态栏。矩阵承担主视觉，原文常驻右侧。证据面板可调宽、资源/证据可折叠；窄屏自动收资源区，证据用侧栏。没有聊天气泡入口或营销首页。

默认选择“训练轮次 / A”，对照 50/80/200 三个值；B 的相关工作提及100轮与本文80轮有明确区分。指标不用于跨条件优劣排名。

## F01–F09 与六交互决策覆盖

- F01：项目概览/文档库、MD/TXT真实导入、预置四格式和来源更新演示；无生产项目管理与真实PDF解析。
- F02：阅读、示例章节、原文块定位、多标签；PDF/DOCX为提取文字，不声称原貌定位。
- F03：真实字面查找/范围；训练预算语义查询预置，始终说明未运行向量模型。
- F04：自动/定向、四级页签、分组、实体语义角色、确认/修正；分析结果预置。
- F05：模板化示例、自定义维度、缺失/人工修正、比较矩阵、共同点/差异及转检索；无真实生成提取。
- F06：临时快速入口、新旧版本双栏及数值变化；预置Diff，不代替旧产品回归。
- F07：统一证据、文档块、逐字合成引文、人工支持状态与失效；没有真实PDF坐标或100%产品指标的证明。
- F08：单条Markdown笔记、跨来源摘录、浏览器自动保存、MD/CSV、演示ZIP往返、任务来源；非生产持久化。
- F09：本地运行、离线/授权演示、进度/取消/失败/重试、重置及导出备份；没有真实模型和后台恢复。

六决策均有对应展示：项目与临时比对；IDE面板；两种发现模式；检索/关联/比较转任务及笔记；更新后标过期由用户决定；文件分享与重导。任务转换保留来源提示，分析只使用预置文档范围，不宣称在任意本地文件上可自动分析。

## 限制与验证

所有文档/作者/数值为合成内容，固定示例模型结果不是事实报告。新维度添加后显示未找到，不假装已提取。来源变更与后台任务仅为状态演示，重跑仍使用同一批预置内容；没有真实增量、版本管理、模型推理及恢复。

不实现 NFR 准确率与性能实验；不启动 E01–E05；不将原型通过称作 MVP 完成。原型浏览器验证、页面截图与已知限制见[验证报告](../validation/mvp-workbench/验证报告.md)。正式开发依然需要 AUD-01、标准集、PoC 和准入门槛。
