# DocLens 原文阅读工作台原型设计 v2

日期：2026-11-26。交付：[交互原型](../../examples/mvp-workbench/index.html)、[操作指南](../../examples/mvp-workbench/README.md)、[本版验证](../validation/mvp-workbench-v2/验证报告.md)。

## 调整依据与目标

小组反馈要求：每个检索片段直接进入完整原文；支持最多三栏独立阅读及更多文档切换；取消固定右侧栏；合并检索与比较入口；笔记可自由选区；关联从文档库启动。用户随后明确要求调整原型查看效果。

本版沿用已有海军蓝/靛蓝桌面视觉和本地HTML入口，不改正式应用源码，也不提前宣称完成新的产品MVP。原需求[requirements.md](requirements.md)和[technical-design.md](technical-design.md)保留，正式需求变更与验收指标需后续同步确认。

## 信息架构

一级入口为“文档”“检索与分析”“笔记”，另有设置/后台任务。分析中央标签包含检索结果、原文对照、对照表、全文差异、关联线索。

- 文档库：选择范围，发现关联，进入检索或原文对照。
- 检索结果：每个片段包含查看原文、加入对照、加入笔记，不依赖辅助侧栏。
- 原文对照：1—3份完整文档，独立滚动/缩放/页码/命中；选区批注与来源查看在各栏完成。
- 对照表：保留统一维度提取/编辑/缺失/证据，点击单元格复用原文查看器。
- 全文差异：手动指定两份文档，不要求自动识别新旧；保留差异算法，取消独立版本模块导航。
- 关联线索：从文档库所选范围发起；结果作为任务标签保留，再进入原文/对照表/笔记。
- 笔记：多条Markdown笔记，既可关联任意正文选区，也可自由记录。

## 阅读交互

点击查看原文默认一栏，加入对照逐步增至三栏。资源面板在阅读时自动收起，可手动展开。各栏有文档选择器与前后按钮；候选排除已在其他栏显示的文档。第四份加入时选择替换栏，保留其他栏阅读位置。

PDF文字关键词按源坐标高亮，自然语言示例高亮实际证据段落。每份示例PDF三页全部可访问；查看命中之后仍可阅读非命中位置。超窄窗口允许阅读网格内部横向滚动，不挤压页面级布局。

笔记引用包含文档、源PDF散列、页码/页范围、块、选区单词范围和逐字摘录。选区扩展到完整单词后在确认框展示。回跳优先使用所存选区位置；源版本不一致、旧版迁入引用或来源缺失时明确失败，不静默重绑。

## 原貌与真实实现范围

四份实际PDF由可重复脚本生成，内容为明确标注的合成研究材料。完整页面由PDFium渲染；透明文字层及坐标取自保存后的源PDF，避免以重排HTML冒充PDF原貌。另提供源PDF文件链接。

原型不包含任意PDF/DOCX的通用浏览器解析器。自然语言、关联、结构化提取与耗时任务使用预置结果；不调用模型，不证明NFR或PoC指标达标。全文字词差异确实使用本地算法，范围为两份≤14,000字符文本，不承诺图像/版式/结构变化。

既有v1存储键不删除；能读取的旧笔记以旧引用保存，不绑定新示例来源。v2分享包使用独立schema并包含多笔记/导入文本/比较成果，不含PDF原件，正式应用兼容与安全仍需另行实现。
