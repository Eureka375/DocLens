# 记住 AI 设置

用户要求 API Key 填写一次后长期复用。沿现有控制器和界面增量实现，不新增依赖。

使用 Windows 当前用户 DPAPI 加密整个设置文件（服务地址、模型、请求格式、密钥），存于应用本地数据目录。相比明文配置可避免磁盘直接泄露；相比新增第三方凭据依赖，使用系统现有能力。保护边界为当前 Windows 用户，不能防御已控制该用户会话的程序。参考 [CryptProtectData](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)。

只保存最近一套设置；密钥严格绑定完整服务地址。显式保存或确认发送时记住有效设置。下次启动恢复非密钥字段，密钥仅在后端取用，不回填到 QML。换地址不会带入旧密钥；模型或格式变化仍可使用同一地址密钥。提供清除入口，清除同时清 AI 缓存。保存失败或文件损坏明确提示，不退回明文；保存失败仍可用本次输入发送。

授权预览仍保留，密钥不进入请求正文、分析预览、日志或交付文件。文件原子替换且临时文件也只写密文。测试全部使用临时目录及虚构密钥，不触碰用户实际设置。
