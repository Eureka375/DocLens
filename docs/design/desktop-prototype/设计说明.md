# DocLens 桌面原型设计说明

2026-11-24 · 设计版本 1.0

## 设计方向

采用 Windows/macOS 桌面生产力软件的多栏工作区语言：常驻左导航、项目面包屑、操作栏、可横向扩展的矩阵和独立原文阅读区。研究内容优先于装饰，不使用手机外框、营销大图、无关照片或虚假头像。浅灰绿色工作台、白色内容层与暖白纸张预览分别表达导航、结构数据与原文。

主色 #16695d；主文字 #233b3a；次级文字 #657572；边界 #e0e5df；纸张 #fbfaf7。界面采用 Segoe UI / Microsoft YaHei / 系统字体；英文文档采用 Georgia、中文文档采用宋体回退。正文 14 px，标题 27 px，标签 12 px 左右。状态在矩阵中使用紧凑字号，同时始终保留完整文字与可聚焦按钮。

布局基准 1440×900，侧栏 208 px，工作区内边距 30 px，矩阵与阅读器间距 18 px，证据栏 360 px。1280 下侧栏缩至 180 px、阅读器 318 px，保持双区；1700 以上阅读器 440 px。更窄窗口依次堆叠内容，矩阵容器独立横向滚动。总览画板固定 1440 宽，外部容器横向滚动，这是画板展示行为。

## 页面与需求映射

- workspace.html：研究任务与文档概览，连接 FR01、FR02、FR03。
- library.html：四格式预置文档、解析状态与提取文本预览；可真实读取本地 MD/TXT 临时预览，对应 FR02 的 UI 流程。
- compare.html：选择 2–4 份预置文档、数据集/方法过滤、矩阵证据切换，对应 FR03。
- evidence.html：章节锚点、原文高亮和引用笔记入口，对应 FR04。
- notes.html：单篇 Markdown 笔记、证据关联、本地保存与导出，对应 FR05 的核心流程。
- version-compare.html：两份预置草稿的三项差异和前后导航，对应 FR07。
- share.html：共享内容确认、默认不附原文、真实生成 Markdown/ZIP，对应 FR06 的导出 UI。
- search.html：P1 扩展，四份合成文本字面检索与结果定位，对应 FR08。
- settings.html：阅读密度、项目显示名与恢复演示设置；自定义维度仅说明 P2。
- desktop.html：以矩阵为起点，通过左导航连续操作。
- index.html：仅包含画板标题、独立入口与 iframe，不内联各页面应用界面；9 个关键界面平铺展示。

## 关键交互规范

矩阵状态与证据数量共同展示。选择矩阵单元格立即更换右侧文档名、实体、状态、章节和逐字引文。未发现项不伪造证据；关联笔记操作解释其不可用原因。合成数据具有稳定文档 ID 和证据编码，可作为前端接入正式数据模型的参照。

点击“更新矩阵”才应用新的文档和维度选择。数量少于 2 或维度为空时给出提示，保留原矩阵结果。生成的矩阵始终来自预置数据，不声称重新分析用户导入内容。加入 D 文档可看到部分提取和证据不足。

笔记显式保存，编辑后显示未保存状态，离开页面有浏览器原生未保存提示。引用操作保存所选实体与文档，并进入笔记页。导出编辑中的 Markdown 不要求先保存；共享报告读取最近保存内容。仅演示单篇笔记，正式应用需扩展列表、增删、草稿与多窗口冲突处理。

版本比对只操作预置 v1/v2 草稿。差异前后按钮循环三项；相同版本禁止执行。新增/删除/修改均有文字标签和高亮。不声称浏览器实现通用 PDF、DOCX 比较或移动识别。

离线演示 ZIP 使用无压缩 ZIP STORE，带 CRC32、UTF-8 文件名和中心目录。默认含 manifest.json、project.json、report.md、README.txt；勾选附原文后增加 originals 下四份合成 Markdown。此包的 schema 为 doclens-ui-demo/1，不是生产项目格式。

## 状态与失败设计

覆盖：部分提取、无命中、上下文不足、无证据引用提示、文档数量不足、维度为空、相同版本、检索空查询、检索无结果、超限文件、PDF/DOCX 解析不可用、未保存笔记、浏览器存储失败、恢复设置确认。

生产层还需实现并实测：解析进度/取消/重试、文件夹授权、跨会话项目保存、坏包验证、快照失效、自动恢复、全部证据列表和批量任务。原型不呈现虚假的解析进度，不用定时器假装调用生产分析服务。

## 工程与接入边界

assets/app.css：主题变量、组件与断点。assets/data.js：四篇合成文档、三个研究实体、逐项状态。assets/app.js：公共壳层、页面呈现、事件、浏览器保存、下载、ZIP。各 HTML 为独立入口，通过 data-page 指定视图；每页共用资源，避免复制侧栏和交互逻辑。

本地 Bootstrap 5.3.3（MIT）提供按钮、网格工具与基础样式。Lucide 0.468.0（ISC）图标保留许可，导航使用工程内 SVG 路径，Lucide 布局图标用于品牌标志与网页图标。无 CDN、外部字体、跟踪请求、图片热链或运行时 npm 依赖。

示例 PDF/DOCX 是提取文本样式预览，不是二进制渲染器。正式开发需把 DEMO 替换为版本化 Project/Document/Evidence/Note 服务，并使用真实文本偏移与块 ID；不能依据示例数组索引定位生产文档。所有用户文本经过 HTML 转义。浏览器 localStorage 仅供合成演示，不作为安全项目存储方案。
