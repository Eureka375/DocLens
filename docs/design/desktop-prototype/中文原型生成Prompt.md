# DocLens 高保真桌面原型生成 Prompt

以下内容可整体复制给设计或编码工具独立使用。

---

你是一名桌面生产力软件产品设计师与前端工程师。请为 DocLens 生成可离线运行、可直接交接给前端开发的中文高保真 HTML 原型工程。请先产出正式需求分析与设计说明，再编写界面，最终实际打开检查并提供截图、运行说明和 ZIP。

产品对象：阅读多篇论文、实验报告的学生、教师与研究人员。核心任务是导入多份研究文档，比较数据集和方法的共同点与区别，逐条核对原文证据，形成关联引用的笔记并离线分享。保留已有双文档版本差异比较。

采用 Windows/macOS 桌面生产力软件设计语言，不做手机界面。1440×900 为优先画布，适配 1280 宽与 1920 宽。采用左侧常驻项目导航、中间对照矩阵、右侧原文证据阅读器；白色卡片、浅灰绿色背景、暖白纸张。参考色：主色 #16695d、文字 #233b3a、次级 #657572、边界 #e0e5df、纸张 #fbfaf7。使用系统中文字体和文档衬线字体，保持稳定行高、清晰层级、较高信息密度和显式键盘焦点。拒绝手机外框、营销首页、无意义渐变、无关 Unsplash 装饰图和虚假统计指标。

先写需求：产品目标、用户问题、旅程、信息架构、P0/P1/P2、编号功能需求、非功能要求、数据模型、状态迁移、可执行验收标准和风险。

P0：项目工作区；PDF/DOCX/MD/TXT 批量导入与逐项解析状态；多篇文档按内置数据集/方法比较；对照矩阵；Markdown 章节与证据导航；原文高亮；关联引用笔记；Markdown 导出；离线 ZIP 共享；双文档版本差异比较。P1：跨文档字面检索和定位、人工复核；P2：自定义维度、OCR、独立授权的 AI。实时协作、云同步暂不实现，不将离线包称为实时协作。

矩阵必须区分：使用线索、仅提及、明确未使用、未发现、证据不足。使用线索需人工核对主体；共同出现不代表共同使用；未发现不等于不存在；主体不明、解析不完整或冲突时不得强行给肯定结论。每个有证据单元格显示条数，点击更新文档名、状态、章节、引文与原文高亮。不能伪造页码或宣称实现任意语义分析。

项目容量基线：单文档 10 MiB、100000 Unicode 码点、PDF 300 页；项目 50 篇、100 万码点；界面默认一次比较 2–8 篇。扫描件提示需 OCR，DOCX/PDF 原貌不可用时标明提取文本。正式应用的性能目标与原型实测分开记录。

实现独立页面：workspace.html、library.html、compare.html、evidence.html、notes.html、version-compare.html、share.html、settings.html；search.html 标为 P1 扩展；desktop.html 为连续操作入口。index.html 仅用 iframe 平铺所有关键页面，提供清晰标题、画板滚动与“单独打开”链接，不将链接当作 iframe 的替代。

使用 HTML + 本地 Bootstrap 或已编译 Tailwind CSS；开源 SVG 图标与许可一起放入工程，不依赖 CDN、外部字体或运行时构建。共用 CSS、JS、示例数据；每页均可独立打开。只有确实需要文档图片时才使用真实且许可合适的资源，优先制作真实文档样式的文本预览。

示例数据使用 4 篇合成文档与稳定 ID。例如 A 在 CIFAR-10 评测并采用 ResNet；B 仅提及 CIFAR-10、采用 ResNet；C 使用 CIFAR-10 与 Transformer、明确未使用 ResNet；D 部分提取、Transformer 主体不明。所有文档、引文和结论显著标记“合成示例”，不能假称真实论文结果。示例状态必须与逐字引文一致。

关键交互：文档选择（少于两篇给出原因）、维度过滤（至少一个）、矩阵点击更新证据、章节锚点滚动、关联证据进入笔记、编辑并显式保存、保存成功/失败提示、离开未保存内容保护、下载 Markdown、选择是否附示例原文、真实生成可解压离线 ZIP、版本差异前后导航、P1 字面检索和结果定位。浏览器读取本地 MD/TXT 可真实实现；PDF/DOCX 如仅预置预览，界面明确说明接入边界。不做虚假分析等待动画。

离线包至少含 README、manifest、项目快照、报告；原始文件默认关闭。提示“即使不附原文件，仍包含提取正文、引文和笔记”。不含 API Key、绝对机器路径。演示包与生产项目格式要分开，不能声称可安全导入正式应用。报告内部导航不依赖作者电脑路径。

工程交接请解释设计变量、布局断点、组件状态、需求与页面映射、Project/Document/Evidence/Note 模型、正式解析/持久化/分析接口接入点。说明 localStorage 只为演示，非生产安全存储；不包含通用 PDF/DOCX 引擎、正式分析服务、实时协作后端或生产性能保证。

检查：在 1280、1440、1920 宽度实际打开各页，检查控制台错误、资源缺失、页面级横向溢出；矩阵允许内部横滚。验证笔记刷新后保留、引文一致、导出 Markdown 可读、ZIP 完整可解压并与勾选项一致。检查无结果、失败、部分提取与未保存状态。提供主要界面截图和如实记录的验证报告。不要把没有执行的检查标成通过。

交付文件：正式需求 Markdown、可行时 DOCX、设计说明、本 Prompt 独立文件、完整 HTML 工程、截图、运行说明与 ZIP。若位于 DocLens 仓库，文档放 docs/design/desktop-prototype，示例工程放 examples/desktop-prototype，截图与验证放 docs/validation/desktop-prototype，ZIP 放 dist/desktop-prototype；不要改动现有应用源码。
