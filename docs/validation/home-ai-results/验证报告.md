# 首页左侧分组AI结果验证

2026-11-22。基线V0.5.0 `a775e01`，交付版本V0.5.1。用户要求在首页左侧对应分组直接看到AI分析结果。

## 修改

- [app.py](../../../src/doclens/app.py)：按已校验证据编号映射Finding到各组，暴露状态、解释、可能影响及本组证据；独立AI更新信号避免每次结果变化重建整个审阅列表，原类别筛选继续可用。
- [ReviewPane.qml](../../../src/doclens/ui/ReviewPane.qml)：显示每组当前状态、首条解释摘要、可能影响、展开全部内容、原文/新版证据按钮。多组共同解释明确标关联编号；失败或未覆盖时保留的旧解释有单独提示，所有模型内容为纯文本。备注编辑即时保存草稿。
- [Main.qml](../../../src/doclens/ui/Main.qml)、[AnalysisDialog.qml](../../../src/doclens/ui/AnalysisDialog.qml)：侧栏加宽，增加“首页查看”；窄窗口用左侧抽屉显示同样分组，点证据后收起抽屉并定位正文。
- [PreviewPane.qml](../../../src/doclens/ui/PreviewPane.qml)：原貌首次跳转先同步布局，延迟回调忽略已过时的组，防止快速跳转回到旧位置。
- [桌面测试](../../../tests/test_desktop.py)：新增归组/状态/共同解释、本组证据索引、失败保留、清缓存、窄窗抽屉和异步备注输入测试；加强原貌快速切换回归。另更新版本元数据、README、[设计](../../design/2026-11-22-home-ai-results.md)、发布记录及冻结控件检查。

## 验证

新增两项测试先失败，分别复现缺少首页AI字段、结果更新导致正在输入的备注丢失；实现后通过。窄窗口测试也先复现首页查看后找不到侧栏，加入抽屉后通过。

完整回归最终 **136 passed in 18.50s**，退出码0。执行：`$env:QT_QUICK_BACKEND='software'; ./.venv/Scripts/python.exe -m pytest -q`。

过程中曾出现1次PDF原貌首次定位超时（135项通过、1项失败），单独重跑通过。核查发现初始ListView布局未完成及旧延迟回调可能覆盖新定位，补充布局同步和组编号校验后，完整136项通过。

独立只读审查未发现Important/Critical；指出窄窗口隐藏侧栏会影响“首页查看”。本轮按核心可用性要求补齐抽屉，并用真实点击测试验证。AI请求、授权、缓存协议和加密设置策略未调整。
