# V0.4.2 AI等待上限与打包验证

2026-11-22。用户在DeepSeek分析时遇到本地30秒超时，要求放宽上限。本轮将所有已支持服务的等待上限调整到120秒；提示显示时长，保留取消与手动重试。未修改20组和12,000字符的单次输入限制，未加入自动重发。

## 修改文件

- [analysis_ui.py](../../../src/doclens/analysis_ui.py)：30,000→120,000毫秒，等待及超时文案说明120秒。
- [test_desktop.py](../../../tests/test_desktop.py)：增加无响应服务下的超时/取消回归，确认中止后释放等待状态、定时器停止、本地第5组仍能跳到“90”、不会自动重发。
- [pyproject.toml](../../../pyproject.toml)、[uv.lock](../../../uv.lock)：版本0.4.2。
- [验证脚本](../../../scripts/verify_windows_release.py)：额外检查冻结模块实际包含120,000毫秒设置，并在包内使用说明标注。
- 根README、发布索引、[发布说明](../../../releases/v0.4.2/README.md)、校验文件、本报告及[打包数据](package-results.json)。源码修复提交 `bf2089b`。

## 结果

