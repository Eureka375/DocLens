本次仅调整本地原型与样例/验证工具；未修改`src/doclens/`正式应用，未调用模型、运行E01–E05或重跑正式应用pytest/构建。需求规格中性能/准确性目标未因此标为通过。

## 实际覆盖

- 主导航为文档、检索分析、笔记与设置；没有独立比较/版本导航，没有固定右侧证据栏。
- 每条检索片段提供完整原文、加入对照和笔记入口；完整三页PDF单栏打开，图像加载成功，文字坐标和高亮存在。
- 收起资源面板后中央工作区仍占可用宽度，阅读器高度和页面宽度有明确检查，避免“元素存在但不可见”。
- 三栏共九页完整原文；各栏独立滚动/缩放；选择器访问第四份文档，前后按钮避免重复文档；上限三栏可见提示。
- 从第三页非命中附录选择真实单词，创建来源笔记；保存页码、摘录和源PDF散列，来源可验证，笔记可回到同一完整原文。
- 多条笔记、无来源自由笔记、自动保存和刷新恢复。
- 对照表单元格复用同一原文查看器；新增自定义字段保持未找到，缺失值不产生虚假证据。
- 全文字词差异实际调用本地算法，比较两份输入的全部提取文字，手动选择基准与对照。
- 关联从文档库启动；三份和两份所选示例范围均按范围展示/打开，不混入未选文档。
- 1280×800、1440×900、1920×1080、720×900，五种分析视图和文档/笔记/设置/任务共36个组合无页面级横向越界。窄屏多栏在阅读网格内部横向滚动。
- 自然语言示例标识预置召回，并高亮证据段落；任务取消/重试/失败、离线授权阻断、实际片段预览。
- MD真实导入/字面检索/全文阅读；Markdown、CSV、ZIP下载，本版ZIP往返保留多笔记/导入文本，坏包不改变当前数据。

## 检查中发现及修正

初次流程在对照表页面寻找仅其他视图存在的按钮而中断，检查脚本改为通过“全文差异”标签进入。截图检查另发现资源面板收起后CSS自动定位使中央区落入零宽网格列；已显式指定网格列，并新增中央可视宽度/高度断言。修正后重跑，随后补充关联范围与精确选区回跳检查，最终77项均通过。前次中断不计作完成验证。

## 已知限制

1. PDF原貌与文字层仅针对随附四份预生成示例，未接入任意PDF/DOCX通用解析器；实际PDF原文件可单独打开。
2. 关键词检索、PDF阅读、笔记和文本差异实际运行；自然语言、关联、结构化提取和任务执行仍预置，不证明模型能力。
3. 选区按相交完整单词保存；没有手绘、任意像素便签、编辑源PDF或真实多人协作。
4. 当前对照表预置A/B/C三份，新导入资料不会自动被模型提取；新增维度明确显示未找到。
5. 全文差异一次两份，单份上限14,000字符，不做图片/版式/结构差异，不静默截断。
6. 分享格式只供本版演示，不含PDF原件/页面，不兼容正式项目或v1包；基础校验不等于生产安全验证。
7. 浏览器存储与源版本失效检查不替代正式项目持久化、文件监控和异常恢复；旧v1存储保持原样。
