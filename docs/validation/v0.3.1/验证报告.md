## 验证

- 打包前完整回归：`python -m pytest -q`，63 passed in 6.78s。
- `uv lock --check --offline` 通过；`git diff --check` 通过。
- 使用项目的打包流程完成新构建。检查冻结程序的 PYZ 存档，确认包含 `doclens.structure`。
- 新 ZIP 通过全部条目的 CRC 校验，包含程序、结构化 TXT 样例、PDF 样例及使用说明。
- 将 ZIP 解压到独立目录后，在只含 Windows 系统目录的 PATH 下启动，去除 PYTHONPATH/PYTHONHOME；分别传入两份结构化 TXT 和两份 PDF，均观察到 DocLens 主窗口，随后正常关闭，退出码均为 0。

## 重复构建

在仓库根目录运行：

```powershell
.\scripts\package.ps1 -OutputDirectory dist/v0.3.1
.\.venv\Scripts\python.exe scripts/verify_windows_release.py 0.3.1
```

若同版本输出目录已经存在，PyInstaller 可能要求确认是否替换；先关闭正在运行的同版本程序。

交付文件为 `releases/v0.3.1/DocLens-V0.3.1-Windows.zip` 和对应 `.zip.sha256`；本机可运行目录为 `dist/v0.3.1/DocLens/`。二进制包、构建缓存留在本地，Git 管理版本元数据、脚本、发布说明及验证记录。原 V0.3.0 及其已有解压目录未改动，FolioMind 未改动。
