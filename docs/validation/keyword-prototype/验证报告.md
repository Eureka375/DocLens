# DocLens 关键词研究原型验证报告

2026-11-26 · 原型 1.2 · 对照[需求规格 0.4](../../design/keyword-research-mvp.md)

Microsoft Edge 实际打开本地 HTML。58 项检查全部通过，未记录到页面错误或外部 HTTP 请求。八个界面分别在 1280×800、1440×900、1920×1080 验证样式和页面级横向溢出。较长的 AI 结果与总览画板允许垂直浏览。检查结果见 [browser-checks.json](browser-checks.json)。

- 主导航只有四项。总览包含八个有标题的独立 iframe，演示入口直接打开关键词页。
- 原词匹配忽略英文大小写，区分 `ResNet` 和 `ResNet-50`。新增、修改和删除词条会更新结果。更换文档范围后，命中数和来源列表同步。
- Diff 实时比较两段示例文本，突出 `50` 与 `100`。切换右侧文档会刷新片段。
- AI 确认窗口显示逐段待发送文本，取消后不产生结果。勾选提交后可看到四类预置用途、部分覆盖数和可点的摘要引文。
- 从第三篇加入引用后，研究笔记显示三条来源。编辑保存并重开，内容仍存在，点击引用可定位对应正文。临时 MD 预览将文档中的标记作为文本显示。
- 实际下载 Markdown 和两份共享 ZIP。校验压缩包 CRC、报告及引文、原文件勾选状态与包内清单，详见 [export-checks.json](export-checks.json)。

长文档案例使用独立的[合成长文档 A](../../../examples/desktop-prototype/sample-documents/视觉编码实验记录A.md)和[合成长文档 B](../../../examples/desktop-prototype/sample-documents/视觉编码文献记录B.md)。现有 DocLens 的研究导入器实际读入两份 Markdown，无解析问题，每篇提取正文约 3.23 万个 Unicode 码点。网页版临时预览也实际打开了 A 文件，并限制正文滚动区域。原型按样例的非空正文段落展示，每篇 12 章、288 个正文段落。

- `ResNet` 命中 72 段，每篇各 36 段。每篇首次展示 8 段，点击后增至 16 段而且保持展开状态。
- 选第 8 章第 172 段进行双栏 Diff；单击跳转到正确章段，通过目录切换第 12 章。证据页只加载当前一章的 24 段供阅读。
- AI 确认页默认只选中当前的两段。勾选超过 20 段无法提交。确认两段后显示每篇命中 36、提交 1、完成 1。长和短案例分别保存笔记。
