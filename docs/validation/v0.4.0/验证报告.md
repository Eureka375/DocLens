# DocLens V0.4.0 打包验证

日期：2026-11-22。本机 Windows、Python 3.13、PyInstaller 6.22.3。

本版实现与测试见[原貌验证](../original-layout/验证报告.md)，其中包含Word真实界面截图和已知边界。完整自动化回归75项通过；独立审查提出的问题均补回归修复。

使用以下流程构建并验证：

```powershell
.\scripts\package.ps1 -OutputDirectory dist/v0.4.0
.\.venv\Scripts\python.exe scripts/verify_windows_release.py 0.4.0 --with-word
```

ZIP CRC全部通过，冻结模块包含 `doclens.structure` 与 `doclens.preview`，随包存在Word转换脚本与新增依赖的许可证目录。生成ZIP后解压到独立目录，在仅Windows系统目录的PATH下，分别传入TXT、PDF、DOCX样例启动；三个案例均观察到DocLens主窗口，正常关闭且退出码0。DOCX案例保留18秒用于本机Word转换。该启动检查不直接读取窗口差异数量，具体分组与高亮由源码回归和实机截图另行覆盖。

实测数据见[package-results.json](package-results.json)。包大小81,300,051字节，SHA-256：

```text
7f2d2daa63d6578f8e3c1caeb1a9ace3e50a94dc3c8a1b5710abae8cedcb882f
```

本机启动路径 `dist/v0.4.0/DocLens/DocLens.exe`，便携ZIP位于 `releases/v0.4.0/DocLens-V0.4.0-Windows.zip`。大型包与构建输出仅留本地；源码、演示文档、截图、记录及小型校验文件由Git管理。

DOCX原貌需要安装并激活Microsoft Word，PDF原貌不依赖Word。另一台干净Windows、不同字体/Word版本、实际AI服务尚未验收。保留V0.3.0和V0.3.1历史包，没有操作FolioMind项目或关闭用户已有Word文档。
