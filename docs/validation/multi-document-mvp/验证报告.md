## 独立审查及修正

独立只读审查发现4个重要问题，均修正并新增先失败后通过的回归：

1. 同句实体状态相互污染：对子句及实体前方提示词分别判断，含否定/对比时保守处理。
2. 长段落重复扫描导致界面停顿：一次构建子句边界、局部窗口判定、证据/矩阵缓存，导入和打开时在后台准备；最大10000条证据。
3. 导出只限制压缩大小，可能生成自身无法重导入的包：导出同时限制解压总量；证据上下文限长，完整正文只输出一次。
4. 重导原文被去重跳过而无法恢复原始文件：相同散列补回原文字节，保持快照和笔记ID。

[首次失败记录](review-regressions-red.txt) · [长段落补充失败记录](performance-red.txt)。上述回归在最终176项测试中通过。另修正轻微问题：新增笔记后编辑器采用返回ID，再保存会更新同一条笔记。最后补充修正多词方法名证据锚点含空格导致Markdown链接无效的问题，见[失败记录](anchors-red.txt)，新增回归已通过。
