# DocLens V0.3.0 验证记录

2026 年 11 月 21 日在项目使用的 Windows 环境验证。

## 自动化回归

`python -m pytest -q` 共 49 项通过。覆盖的新增场景包括：

- 文本型 PDF 与 TXT 混合比对。PDF 提供页码和提取行号，数字修改保留字符级选区。
- 有文字的旋转页、只有图像的页面、混合页、加密文件、异常内容和解析上限。超限的重复表单会作为解析错误报告。
- 文件夹检索跳转至 PDF 的命中行。坏文件不阻断其他文档，混合 PDF 的提示在复用索引后仍然包含页码。
- 长文档的远距离改动分组、唯一文本移动、移动附近的真增删和重复文本。桌面用例用下拉列表在 PDF 的两处差异之间跳转，检查蓝色高亮、双侧选区和 AI 预览中的页码。

## Windows 便携版

使用 `scripts/package.ps1` 构建。以仅包含 Windows 系统目录的 PATH 启动解压后的 `DocLens.exe`，传入两份 PDF 示例，确认出现主窗口并正常退出。发布 ZIP 通过完整性检查，内含应用、两份示例和操作指南。
