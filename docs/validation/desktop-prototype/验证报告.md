# DocLens 桌面设计原型验证报告

日期：2026-11-24。对象：独立 HTML 原型与需求文档，非正式 DocLens 应用版本。

## 检查环境与结果

Windows 本机 Microsoft Edge 无界面浏览器，真实加载本地 HTML/CSS/JS；页面尺寸分别为 1280×900、1440×900、1920×900。检查脚本为 [validate_desktop_prototype.mjs](../../../scripts/validate_desktop_prototype.mjs)。运行 `node scripts/validate_desktop_prototype.mjs` 会创建项目 build 下独立浏览器配置和演示下载文件，并在结束时关闭自身启动的浏览器。

最终运行共 69 项检查通过，0 项失败，0 条浏览器运行时或资源错误。详见 [browser-checks.json](browser-checks.json)。其中 54 项覆盖 9 个关键页面在三种宽度下的页面级横向溢出与样式加载检查；其余验证矩阵、引用、笔记、检索、版本导航、文件读取、交互入口及 iframe 总览。

此结果证明本次演示工程的已测流程可运行，不是正式需求的全量产品验收。未修改或运行现有应用源码的回归测试。

## 已实际操作的流程

- 点击 CIFAR-10 / B，右侧状态切换为仅提及，逐字引文与示例正文完全一致。
- 勾选第四篇文档更新矩阵；点击 Transformer / D，显示证据不足及对应引文。
- 关联证据进入笔记，引用正确指向 D 文档；保存正文后刷新，内容保留。
- 下载 Markdown 笔记，下载带/不带原始示例文本的两个 ZIP。
- 对 ResNet 执行字面检索，得到 3 个段落结果；点击结果后原文高亮包含查询词；不存在词显示无结果。
- 版本差异前后导航更新内容；交换 v1/v2 后继续导航仍保持方向。
- 实际选择本地 MD 文件，读取并转义其中 script 标签，未作为脚本执行。
- desktop.html 加载可交互矩阵；index.html 包含 9 个有标题的 iframe。

ZIP 已用 Python zipfile 打开并校验 CRC，两包均通过；不附原文包 4 个条目，附原文包 8 个条目。manifest 中 originals 值与内容一致，详见 [export-checks.json](export-checks.json)。演示包 schema 为 doclens-ui-demo/1，未测试正式应用重导入，不作兼容承诺。

## DOCX 检查

[需求 DOCX](../../design/desktop-prototype/需求规格.docx) 由与 Markdown 相同正文生成，Word 渲染为 6 页，逐页检查无缺字、文字重叠或越界；清除了模板标题装饰线。当前环境未提供文档工作区依赖加载器及配套 render_docx.py，因此采用本机 Word 的后台只读导出和页面图像检查。中间 PDF 与检查图像保留在 build，不混入正式发布包。

## 适用边界与未验证内容

全部研究文档和结果都是合成示例。PDF/DOCX 仅预置提取文本视图，没有浏览器通用解析、原貌渲染或通用研究分析。临时 MD/TXT 预览不加入研究矩阵。笔记演示仅单篇、保存在浏览器，未实现生产项目持久化、多窗口冲突处理和安全重导共享包。

macOS、Safari、Firefox、Chrome 独立版本、生产解析性能、50 篇项目容量和恶意 ZIP 导入不在本轮实测范围。无障碍尚未作完整审核；紧凑状态标签部分小于正式产品字号目标，正式开发需增大并检查高密度矩阵布局、屏幕阅读器及对比度。不能把原型截图通过等同于非功能要求全部达标。
