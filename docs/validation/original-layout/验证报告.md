# 原貌比较验证

2026-11-22，在本机 Windows、Python 3.13、安装的 Microsoft Word 上验证。

实现依据[设计](../../design/2026-11-22-original-layout.md)与[计划](../../superpowers/plans/2026-11-22-original-layout.md)。用户选择依赖本机 Word 以优先保留排版；原貌是只读页面预览，差异仍由正文比较提供。

## 验证结果

- 完整测试最终 75 passed in 11.96s。原有测试不调用外部 Word；新增真实 PDF 页面/坐标和窗口用例，包含原貌与文字切换、跨页跳转、纯新增/删除双侧同步、重置删除临时预览。
- Word 演示实机结果：[实测数据](word-results.json)。两侧各2页，4组差异，每侧第一页3处标记、第二页1处；标题、彩色字体、图片、表格和分页均正常显示。图片与页眉仍不参与文字比较，界面保留范围提示。
- [第一页截图](word-original-layout.png)可见原格式与表格内数字高亮；[第二页截图](word-page-two.png)检查跨页导航。
- PDF 回归覆盖旋转页面坐标、来源在读取后变化、重复文本不猜测、纯空白变化提示、页数超限、Word导出失败保护源文件、Word启动尚无PID时取消模拟、纯新增的无编辑侧导航锚点。
- 独立审查发现的取消、空白提示和纯新增/删除另一侧导航问题均已按失败用例修复；针对性复查4项通过。

## 安全与资源边界

Word只读取临时副本，禁用宏与打开时链接更新，不保存原件。用探测文档窗口句柄确认专用Word进程，并排除转换前已存在的进程；超时/取消只处理已验证的进程句柄，不按进程名关闭Word。取消每次轮询检查，先给helper两秒清理宽限；若COM初始化尚未发布PID，只终止辅助进程，不强行终止未知Word。Word转换总时限90秒。

PDFium所有调用在互斥锁内，显式关闭文档/页/文本/位图对象。最多80页、6000万渲染像素、15万字形、120MiB图像临时存储。生成页面在临时目录，重置、取消及正常退出清理。异常强制结束进程时无法保证临时目录立刻删除。

匹配先按完整文本块唯一对应；短表格值多次出现时尝试唯一的相邻块上下文。无法确认的位置不画标记并提示核对。字符矩形来自实际PDF字形，旋转通过页面坐标变换处理；这不等于完成了版面、图片或格式变化比较。

## 依赖与限制

pypdfium2 5.15.2、Pillow 12.3.0 固定在依赖锁中。查阅了[PDFium Python API](https://pypdfium2.readthedocs.io/en/stable/python_api.html)、[Word PDF 导出](https://learn.microsoft.com/en-us/office/vba/api/word.document.exportasfixedformat)与[Word窗口句柄](https://learn.microsoft.com/en-us/office/vba/api/word.window.hwnd)文档；随包保留依赖发行物中的完整许可证。没有加入PyMuPDF等其他PDF运行时。

未验证另一台干净Windows、不同Word/字体版本和真实大文档集合。字体缺失、外部资源和Word自身兼容性可能影响预览；这是本机Word实际生成的页面，不承诺所有电脑逐像素一致。不能可靠映射时须使用文字视图核对；纯扫描PDF仍不支持直接比对。
