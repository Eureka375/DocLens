## 使用行为

首次填写地址、模型、格式和 API Key 后，点击“保存设置”；确认发送也会自动保存。下次启动恢复地址、模型、格式，密钥框留空且提示“已保存”，后端按完整服务地址取用密钥。不会将保存的密钥重新回填到 QML。可以输入新密钥替换，或清除保存的设置。仅保存最近一套设置；不自动更新供应商撤销/过期的密钥。

Windows 当前用户 DPAPI 加密整套设置，文件在应用本地数据目录的 `ai-settings.bin`，不在仓库或发布交付目录。采用临时密文文件加原子替换，失败保留旧设置。系统保护说明：[CryptProtectData](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)、[CryptUnprotectData](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptunprotectdata)。此保护不防御已控制当前Windows用户会话的程序。

## 验证

执行 `$env:QT_QUICK_BACKEND='software'; ./.venv/Scripts/python.exe -m pytest -q`。最终 **123 passed in 15.90s**，退出码0，较基线新增13项，完整记录见日志。`git diff --check` 通过。

新增存储模块先运行测试因模块缺失失败；新增控制器测试先因缺少保存接口和未保存而失败；故障测试复现“保存新密钥失败却清空输入”，改为只在保存成功时清空后通过。

独立只读审查确认1项故障路径问题：Windows临时密文被占用时，清理异常会覆盖保存错误，阻止本次发送。新增双故障测试先失败，再捕获清理异常以保留受控保存错误，完整123项回归通过。若系统阻止清理，遗留临时文件也只有密文。

测试使用虚构密钥和临时目录，实际调用 Windows 加密API，未读取或更改用户真实设置。网络通过现有模拟服务验证；未发送真实文档或使用真实凭据。保留原有预览确认授权、证据跳转、本地比较、检索及原貌预览回归。

## 限制
