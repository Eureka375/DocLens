## 发布方式

使用 [publish_github_releases.py](../../../scripts/publish_github_releases.py) 做本地CRC/SHA-256预检，再创建Release草稿、上传ZIP与校验文件、核对GitHub资产的size/state/digest后公开发布。已有同名附件只核对，不覆盖；最新版本为V0.5.1。正常Git凭据只在进程内供GitHub CLI使用，不写入源码、报告或日志。

命令：`.venv/Scripts/python.exe scripts/publish_github_releases.py --publish`。默认无参数仅预检；`--verify-only`只核对远端，不创建Release或上传附件。新增版本需在脚本中明确登记版本和目标提交，避免把不同版本都关联到当前HEAD。

具体版本、源提交、远端附件名称、下载地址与校验结果见[upload-results.json](upload-results.json)。发布索引见[releases/README.md](../../../releases/README.md)，在线入口为[GitHub Releases](https://github.com/Eureka375/DocLens/releases)。
