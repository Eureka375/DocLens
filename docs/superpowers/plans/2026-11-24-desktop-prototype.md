# DocLens 桌面设计原型交付计划

目标：在不改动应用源码的前提下，提供正式需求基线、独立离线 HTML 原型、开发说明、中文生成 Prompt 与实测截图。

架构：examples/desktop-prototype 中每页为独立入口，共用 assets 下的样式、脚本和合成示例数据。index 只平铺 iframe；desktop 为连续操作入口。Bootstrap 本地分发，使用 Lucide 开源图标。浏览器本地存储只保存演示笔记与设置。

1. 编写 docs/design/desktop-prototype/需求规格.md，完成用户旅程、信息架构、优先级、需求编号与验收标准。
2. 编写设计说明和独立 Prompt，落实桌面三栏、矩阵证据状态、隐私与错误状态。
3. 实现页面及共享样式、数据、交互；仅对 TXT/MD 提供浏览器真实读取，PDF/DOCX 明示为生产解析接入点。
4. 用本地浏览器实际检查 1280/1440/1920 宽度、页面错误和关键交互，保存截图及结果。
5. 生成 DOCX 并尝试本地可用的排版渲染；检查后打包至 dist/desktop-prototype，说明检查范围。
6. 只提交本次新增的设计原型文件并推送；不纳入工作区已有源码修改、缓存或构建输出。
