# 结构化解析与分层比较实施计划

用户已要求直接在当前仓库实现并验证。本轮保留 Python / Qt 桌面架构，原文只读，不接触 FolioMind。

1. 核验六个项目的实际仓库、算法源码和许可证，记录采用与暂缓的原因。同名 DocGraph 无法从缓存预览唯一确定，明确本轮核验对象。
2. 先添加失败测试：DOCX 标题/列表/嵌套表格、TXT 标题、PDF 页码、连续段落修改和跨章节重复文本。
3. 扩展不可变 TextBlock：类型、标题级别、章节路径、嵌套表格坐标、PDF 页码；保持原文字符偏移和旧构造方式兼容。
4. 比较使用唯一标题路径作为顺序锚点，区域内沿用有工作量上限的块匹配；相似且一一对应的连续修改细分为段落，再生成字符级证据。标题不可靠、重命名或重复时回退现有算法，不宣称语义等价。
5. 检查现有全文检索实现和版本识别缺口，记录后续方案，不在本轮引入模型或自动版本清理。
6. 全套测试、示例回归、源码审查；在 docs/validation/structured-comparison/ 保存验证与已知限制，更新 README；验证后按功能提交并推送。

验收重点：表格合并与嵌套不重复、章节重复条款不跨区配对、Unicode 定位不漂移、无法对齐的区域不丢文本、取消与退化标志保留、既有检索/AI/窗口回归通过。

方案取舍：直接引入 Docling 能提供更强版面解析，但模型和打包成本不适合当前便携版本；继续纯平铺比较无法利用已有 DOCX 结构；本轮选择轻量结构元数据与确定性分层比较。
