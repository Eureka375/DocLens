# 原貌比较

在 DocLens 中选择[原版 Word](原版.docx)和[新版 Word](新版.docx)并开始比对。

需要本机安装并激活 Microsoft Word；首次生成预览可能耗时数秒。文档仅以临时副本只读转换，不保存原件。

预期两侧各显示两页，保留蓝色标题、页眉、表格、图片和分页。正文共 4 组修改：交付 7→3 天、金额 100→200 元、表格 7→3 天、留存 45→90 天。上一处/下一处可跳转到不同页面。

各列可分别切换“原貌”和“文字”，使用 − / 适宽 / + 缩放页面。原貌保留字体与图片，不表示已经比较了字体、图片或页眉内容；这些项目的变化仍不在当前正文差异范围内。
