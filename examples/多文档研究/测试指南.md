# 多文档研究 MVP 案例

四份合成文档只用于功能演示，不代表真实论文结论。`01-vision.md`、`02-baseline.txt`、`03-text.docx`、`04-retrieval.pdf` 覆盖四种格式。

1. 打开 DocLens，点击顶部“多文档研究”。输入项目名称并新建，批量选择上述四份文档（不要选本指南或导出报告，以免它们也被分析）。
2. 矩阵中 BERT 四列均为使用线索；CIFAR-10 前两列为使用线索、第三列为仅提及、第四列未发现。ResNet 第一列使用线索、第二列否定使用、第三列仅提及、第四列未发现。ImageNet 第一列使用线索、第四列否定使用。MNIST 第一列提及、第二/四列使用线索。
3. 点击第一份文档的 BERT 单元格，再点证据。右栏应选中 BERT；前面的 emoji 不应影响定位。点击“文档与目录”，选择 Markdown 文档，点击章节目录应跳转高亮。
4. 点击“笔记”，勾选关联当前证据，保存一条笔记；编辑、跳回证据、保存项目，关闭后再打开项目检查。移除文档后其笔记仍保留，关联清除。
5. 导出 Markdown，可阅读矩阵、笔记、证据和文档内容，点击目录内部链接跳转（需支持 Markdown HTML 锚点的阅读器）。导出 ZIP，分别取消/勾选附带原始文件，在新项目打开 ZIP 验证重导入。

也可直接打开 [演示项目](demo-project.json)，或重导入 `demo-share-without-originals.zip`。示例项目含四份原文；不附原文的 ZIP 仍含提取全文、证据和笔记。生成器：`scripts/create_research_examples.py`。

状态是可解释的规则线索，不能替代阅读。词典外实体不会出现。扫描 PDF、公式、图像、跨句指代不在本版保证范围。
