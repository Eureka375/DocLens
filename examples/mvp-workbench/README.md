# DocLens 原文阅读与分析原型 v2

直接双击 [index.html](index.html) 用 Edge/Chrome 打开。无需安装依赖、启动模型或联网。建议先在1440×900或更宽窗口体验三栏；窄屏可在阅读区内部横向滚动。

本版依据小组反馈调整交互：移除固定右侧证据栏，合并检索与比较入口，把关联启动前置到文档库。它仍是界面与交互原型，不代表完整MVP或E01–E05已完成。[原型调整说明](../../docs/design/mvp-workbench-prototype.md) · [本版验证报告](../../docs/validation/mvp-workbench-v2/验证报告.md)。

## 推荐体验

1. 默认打开“检索与分析 / 检索结果”。每个片段有“查看原文”“加入对照”“加入笔记”。字面检索实际使用随附PDF的文本。
2. 点击“查看原文”，打开完整三页PDF的对应位置。可以滚动到其他页面、切换页码、缩放、查看目录，并通过“PDF文件”打开实际源文件。
3. 点击“返回检索结果”，从另一片段“加入对照”；或在阅读器“添加文档”。最多同时三栏，各自独立滚动。已选A/B/C时，顶部“原文对照”可一次打开三栏。
4. 每栏通过文档选择器和 `<`、`>` 切换其他文档，避免重复显示同一份；已有三栏时加入新文档会询问替换哪一栏。关闭栏位可以回到双栏或单栏。
5. 在任意PDF正文拖选文字，上方出现“写笔记”。可以选择非命中段落、其他页面或附录；也可以用“当前片段笔记”默认摘录当前命中。保存后在“笔记”中点击“回到原文”。
6. 在“笔记”创建无来源的自由笔记；支持多条笔记，编辑后约600ms保存到当前浏览器。旧版v1浏览器数据不被覆盖，其笔记如能读取会作为旧引用迁入，不能自动绑定到新PDF。
7. 在“对照表”查看多维度结果，单元格有证据时直接进入同一套完整原文查看器。可添加自定义维度（保持未找到）、人工修正、导出CSV。
8. “全文差异”由用户选择基准和对照文件，用本地文本算法比较全部提取文字；不用自动判断新旧。点击“查看两份原文”可进入双栏。这个原型不比较版式、图片或公式。
9. 在文档库勾选文章，点击“发现关联”。线索保存在中央“关联线索”标签中，可查看原文对照、转为对照表或写笔记。只有与所选示例范围对应的预置线索会展示，选其他资料不会假装完成分析。
10. 顶部“导出与分享”下载Markdown、CSV和演示ZIP；设置里可导入演示ZIP。任务页可体验取消、失败及重试，来源变化也可演示过期/失效处理。

## 原文为何能够完整查看

`sample-documents/`包含四份真实PDF文件，每份三页；论文、作者与数值均为合成案例，并非真实研究结论。`pdf-pages/`是PDFium从这些源PDF渲染的完整页面，`pdf-data.js`保存从PDF提取的文字与坐标。阅读器显示实际页面图像，并叠加可选择的透明文字层及高亮，不是用HTML重新排版片段。

原型使用预先生成的页面与位置数据，不包含能处理任意新PDF的浏览器解析器。PDF原貌渲染示例已实际运行，通用PDF/DOCX导入、真实语义搜索、开放实体及自定义字段模型提取仍未接入。

生成或更新样例可运行：

```powershell
.\.venv\Scripts\python.exe -B scripts/create_workbench_pdf_samples.py
```

此脚本使用现有pypdf、PDFium依赖生成确定性示例，不下载论文或模型。

## 实际功能与演示边界

实际运行：字面查找、1—3栏完整页面、关键词高亮、文档切换、页码/缩放/独立滚动、任意文字选区摘录、来源回跳、多笔记保存、维度定义/人工编辑、两份全文字词差异、MD/TXT导入、Markdown/CSV/ZIP下载与本版包重导。

预置演示：自然语言召回、关联分组与语义角色、矩阵提取、任务执行/取消/失败、源文件变化和外部服务授权。没有真实Embedding、模型推理、后台文件监视或生产任务恢复。

- 自然语言查询可用“训练预算”体验，标的是相关证据段落，不把问句伪装成原文关键词。
- 全文差异仅针对两份不超过14,000字符的文本，超限会拒绝而非偷偷截断；不代表正式Diff引擎能力限制。
- MD/TXT按UTF-8读取，单文件≤500KB、最多保留前100,000字符，合计最多30份。导入文本可搜索、阅读和摘录，不会自动进入预置矩阵/关联。
- PDF正文选区会扩展到相交的完整单词，确认框展示实际保存的摘录；没有任意坐标贴便签、手绘或修改PDF。
- 存储依赖当前浏览器/当前地址，不能替代正式项目保存和备份。保存失败会提示，请导出需要保留的内容。
- ZIP格式`doclens-workbench-demo/2`，两个固定条目`manifest.json`和`report.md`、未压缩、≤5MB，只供本版原型重导；不含PDF原件和页面图像，来源引用需要接收者使用同版本随附示例。不兼容正式应用或v1分享包，也不构成生产安全验收。

```powershell
node scripts/validate_mvp_workbench_v2.mjs
```

浏览器验证使用Node22+与本机Edge，检查多尺寸和关键流程，输出位于`docs/validation/mvp-workbench-v2/`。不执行模型或PoC。
