# DocLens 新需求工作台交互原型

直接双击 [index.html](index.html) 用 Edge/Chrome 打开。无需安装依赖、启动模型或联网。最适合在 1440×900 及以上桌面窗口体验，也检查了 1280、1920 和窄窗口。

这是依据 [2026-11-26 需求基线](../../docs/design/requirements.md) 制作的本地交互原型，不是完整产品 MVP。所有论文、作者、数据和分析为合成资料；语义、关联、矩阵提取和版本变化均使用预置内容，不代表已运行模型或通过 PoC。

## 推荐体验顺序

1. 默认打开结构化比较。点选“训练轮次”中的 200 epochs，右侧显示对应论文的原文。点击“确认支持”“加入笔记”或“打开原文”。
2. 添加自定义维度（如推理延迟），观察“未找到”状态；选中单元格后可以人工编辑，原始证据保留。原型不会对新增维度执行真实提取。
3. 在跨文档检索中查询 MobileNetV3，实际字面查找会定位到 B。切换语义模式查看“训练预算”的预置召回，再转为结构化比较。
4. 关联发现中切换相同、相似、实体、主题；对比 B 的“相关工作提及”和“本文实际使用”。确认或修正关联。
5. 打开研究笔记，编辑 Markdown；约 600ms 后自动保存到此浏览器，刷新后可继续。浏览器限制本地存储时会显示失败提示，请导出备份。
6. 文档库中“演示文档更新”会标记结果过期；“演示旧原文不可用”会显示证据失效。旧结果继续可见，不跳到新版相似位置。
7. “开始比较/发现”进入后台任务演示，可以取消、重试；也可模拟失败。不会执行实际解析、模型调用或性能测试，旧矩阵保留。
8. 顶部“导出与分享”可下载 Markdown、CSV、ZIP。ZIP 包需要确认正文与笔记内容；在项目工作台可重新导入，确认后替换本原型项目。

## 实际可操作与演示边界

实际在浏览器运行：页面/标签/面板切换、证据选择、人工状态、维度定义、单元格编辑、字面查找、MD/TXT 导入阅读、笔记保存、MD/CSV/ZIP 下载、此原型 ZIP 重导、坏包保留当前项目。

预置演示：PDF/DOCX 提取正文、章节、语义召回、四级发现、结构化提取、版本 Diff、任务执行/失败、外部授权。没有向量索引、开放实体算法、真实解析器或模型后端。原始 PDF 原貌与像素坐标未实现，不称为生产证据定位验证。

MD/TXT 导入只读 UTF-8、单文件不超过 500KB，最多预览前 100,000 字符，最多 30 份；这些是原型限制，不是修改需求基线。新增文本可在文档库阅读，并在检索范围中勾选进行字面查询，不会自动加入预置矩阵或关联组。

ZIP 为 `doclens-workbench-demo/1`，只有 `manifest.json` 与 `report.md`，最大 2MB，仅支持本原型导出的未压缩 ZIP；不含原始 PDF/DOCX，但包含提取正文、笔记、人工状态及比较结果。包格式与正式 DocLens 不兼容；导入器只为公开演示数据提供基础校验，不作为正式应用安全实现。Markdown/CSV 单独导出也请先核对内容。

原型只编辑一条笔记；“新建笔记”会先提示替换当前笔记。来源更新和任务生命周期为可见交互演示，没有实时文件监视、真实源版本归档或后台任务恢复服务。

笔记与人工状态保存在当前浏览器、当前访问地址的 localStorage；不是桌面应用项目文件，不保证跨浏览器共享。需要保留时导出 ZIP；清理浏览器数据或确认重置后无法自动找回。

## 页面与文件

- `index.html`：唯一入口；`workbench.css`：桌面与窄屏布局。
- `demo-data.js`：四份合成文档与比较结果；`workbench.js`：交互和浏览器存储。
- `archive.js`：沿用旧原型自有代码中的未压缩 ZIP 写入器，无远程脚本/字体依赖。

IDE 工作台保留最左功能栏、左资源、中工作区、顶部标签、右证据/目录/笔记、底部状态。资源与证据面板可折叠，右侧分隔线可拖动调宽；窄屏证据以侧栏显示。普通文档并排阅读未新增，版本比对仍有独立双栏演示。
